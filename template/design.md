# 前端网页作品集设计规范

本规范以当前 `index.html` 与 `style.css` 的实现为准。整体风格为深墨绿底色、珊瑚红点缀、灰绿色卡片与浅白文字；通过克制的装饰、充足留白和非对称圆角建立视觉识别。

当前介绍区保持简单：红点、标题「xyfang 的前端网页作品集」、说明「这是我的前端网页作品，点击跳转到具体的页面」。作品区采用两列卡片，移动端切换单列。

## 2. 字体与层级

### 字体族

使用系统无衬线字体，不依赖外部字体下载：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

浏览器预览地址与简介代码图形使用 `monospace`。全局启用 `-webkit-font-smoothing: antialiased`。

### 字号、字重与行高

行高为无单位倍数；未单独设置的元素继承全局 `1.7`。字重为 CSS 声明值，实际显示取决于系统字体支持。

| 元素 | 桌面字号 | 移动端字号（≤640px） | 字重 | 行高 | 字距 |
| --- | --- | --- | --- | --- | --- |
| 页面主标题 `h1` | `clamp(34px, 4.4vw, 54px)` | `clamp(30px, 7.8vw, 40px)` | 650 | 1.42 | -1.8px；移动端 -1px |
| 页面介绍正文 | 16px | 13px | 400 | 1.95 | 默认 |
| 卡片标题 `h3` | 17px | 17px | 600 | 1.7 | -0.3px |
| 卡片正文 | 13px | 13px | 400 | 1.85 | 默认 |
| 全局正文基础 | 15px | 15px | 400 | 1.7 | 默认 |
| 导航品牌 | 17px | 17px | 650 | 1.7 | -0.4px |
| 导航链接 | 13px | 13px | 400 | 1.7 | 默认 |
| 按钮文字 | 14px | 13px | 550 | 1.7 | 默认 |

### 保留的扩展样式

当前介绍区已移除大段口号和按钮，但 CSS 保留以下样式供后续复用：

- 二级标题 `h2`：29px，移动端 26px；字重 600，行高 1.7，字距 -0.7px。
- 英文眉题 `.eyebrow`：10px，移动端 9px；字重 500，行高 1.7；字距 2.5px，移动端 1.7px；颜色 `#8FA69B`。
- 品牌后缀：12px，字重 400，字距 0.2px；颜色 `#8A9E96`，移动端隐藏。

## 4. 组件样式

圆角的四个值按「左上、右上、右下、左下」顺序书写。

### 按钮

当前可见按钮为导航中的「探索作品」。主按钮与次按钮样式保留在 CSS 中，当前介绍区不显示。

| 类型 | 背景与边框 | 圆角 | 尺寸与内边距 |
| --- | --- | --- | --- |
| 主按钮 `.button-primary` | 背景 `#F23F60`，1px 实线边框 `#F8607B` | `26px 5px 5px 26px` | 最小高度 48px，内边距 `11px 24px` |
| 次按钮 `.button-secondary` | 背景 `#5D7068`，1px 实线边框 `#77867F` | `5px 26px 26px 5px` | 同主按钮 |
| 导航入口 `.nav-cta` | 透明背景，1px 实线边框 `#40524B` | `5px 20px 20px 5px` | 内边距 `8px 17px` |

- 主按钮与次按钮文字继承浅白色；文字与图标间距 22px，移动端 12px。
- 移动端主、次按钮左右内边距降为 18px；导航入口隐藏。
- 主、次按钮默认无阴影，悬停上移 2px，背景与位移过渡均为 0.2s。
- 左右按钮组合通过相反方向的大圆角形成连贯轮廓。

### 作品卡片

- 背景：`#192B28`；边框：`1px solid #2A3E38`。
- 默认圆角 6px，默认无阴影，内容溢出隐藏。
- 桌面四张卡片共同形成一个外侧圆润、内侧克制的矩阵：第一张左上角、第二张右上角、第三张左下角、第四张右下角分别为 34px，其余角为 6px。
- 移动端所有卡片基础圆角恢复为 6px，仅第一张左上角、最后一张右下角为 30px。
- 可点击作品卡片悬停：上移 5px，边框变为 `#547167`，阴影为 `0 14px 30px #00000020`；过渡 0.25s。
- 简介卡片使用相同容器外观，不应用链接卡片的悬停效果。
- 作品编号：18×18px 圆形，主色背景，深色数字。
- 标签：透明背景，1px 实线边框 `#364B42`，20px 圆角。

### 卡片中的浏览器预览

- 边框：`1px solid #486052`；圆角 7px；阴影 `0 12px 22px #00000030`。
- 顶栏高度 22px，背景 `#263D33`，左右内边距 9px；圆点为 4×4px，间距 4px。
- 图片宽度 100%、高度自动、宽高比 1.95，使用 `object-fit: cover`；注册表单预览定位为 `center 44%`。
- 图片滤镜：`brightness(0.76) saturate(0.65)`，使浅色截图融入深色页面。
- 预览框默认透明度 0.85；默认变换为 `perspective(800px) rotateX(3deg) rotateY(-5deg) rotateZ(-3deg)`；问答卡片的 Y、Z 旋转分别为 5deg、3deg。
- 作品卡片悬停时预览框恢复无变换、透明度 1，过渡 0.3s。

### 导航栏

- 与页面使用同一背景，不加独立阴影。
- 底边框为 `1px solid rgba(164, 180, 175, 0.1)`。
- 品牌与导航链接两端对齐、垂直居中。
- 品牌图标 30×30px，背景为卡片色，基础边框色，圆角 `10px 3px 3px 3px`。
- 导航链接默认次要文字色，悬停变为主要文字色，颜色过渡 0.2s。
- 移动端保留品牌和「作品 / 关于」链接，隐藏品牌后缀与导航按钮。

### 红点与页脚

- 顶部红点使用主色填充、1px 实线边框 `#F75E79`、50% 圆角，不加阴影。
- 页脚顶部使用 `1px solid #253A30` 分隔线，背景沿用页面背景。

## 5. 交互与可访问性

- 作品卡片使用原生链接，在新标签页打开，保留 `rel="noopener noreferrer"`。
- 键盘焦点使用 `3px solid #FF7C93` 描边，与元素间隔 6px。
- 页面提供「跳转到作品」链接；平时移出视口，键盘聚焦时显示。
- 页面使用平滑锚点滚动，`scroll-padding-top: 32px`。
- 在 `prefers-reduced-motion: reduce` 下关闭平滑滚动与过渡动画。
- 沿用当前精简介绍内容，后续扩展优先复用既有色板、层级与圆角规则。
